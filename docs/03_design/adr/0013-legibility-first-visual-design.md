# ADR-0013: 見やすさ優先のデザイン（白×墨×赤、Zen Kaku Gothic New＋Inter、ヒーローのみ茶色）

## 文書情報

| 項目 | 内容 |

| 日付 | 2026-10-22 |
| ステータス | Accepted |

## コンテキスト

- 窓口の指摘: 「サイト全体の色の変化が単調で、似た色で統一されているがメリハリがなく、どこを読めばよいかわかりにくい」。
- 方向 A「ヘリテージ・ペーパー」（ベージュの紙＋えんじ、細い罫）は統一感はあるが、背景・カード・罫・アクセントの明度差が小さく、
  見出し・操作・補足の強弱がつきにくかった。
- 配色だけの調整案と、色・文字の大きさ・配置・書体まで変える 2 案（A: 白×墨×赤、B: 別案）を見本で示し、A が選ばれた。

## 決定

| 項目 | 決定 |
|---|---|
| 色 | 背景 白、文字 墨 `#141414`（18.4:1）、補足 `#5a5a5a`（6.9:1）、沈んだ面 `#f5f4f1`、区切り `#e3e1dc`。アクセント 赤 `#a3121c`（白に対し 7.9:1）は CTA と「今ここ・選択中」だけ。紙テクスチャは使わない |
| ヒーロー | 店内の茶色を残す（写真未着の間は従来のプレースホルダー）。下に黒の幕（0→72%）を敷き、白の文字を載せる |
| 書体 | 和文 Zen Kaku Gothic New（500/700/900、`preload: false`）、欧文・数字 Inter（500/700/800）。`next/font/google` で自己配信 |
| 文字 | 本文 17px・行間 1.8・太さ 500。見出し 28px／900、英字の小見出しは赤 |
| 配置 | トップはヒーロー → 受付・定休日・徒歩の 3 列 → 赤い CTA → 予約欄（進行バー＋カードのステップ＋1 件 1 カードのメニュー）→ アクセスの帯 → 墨のフッター |
| 範囲 | 顧客サイトは `body.site` に限定した上書き（`globals.css` 末尾）。管理 PWA は色トークンの変更だけを受ける |

## 結果

- 良い点: 見るべき場所（CTA・今のステップ・料金）が色と太さで一目でわかる。白背景で写真が映える。文字のコントラストは全て AA 以上（主要な組は AAA）。
- 注意: 和文の Web フォントは Noto Sans JP から Zen Kaku Gothic New に変わり、太さ 900 が増えた分だけ転送量が増える（`unicode-range` の分割で必要な字だけ取得、プリロードなし）。
- v0.2 で外した「本文上部の CTA」をヒーロー直下に戻す（窓口の選択による）。
- 管理 PWA の背景もベージュから白に変わる。部品の形・配置は ADR-0011 のまま。
- 2026-10-23 追記: 窓口の希望で余白を広げた（DG-001 v0.6）。色・書体は変えず、間隔だけで落ち着きと洗練を出す。
