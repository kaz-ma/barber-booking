## 店舗HP（https://neuer.frei.jp/）から読み取れた事実

### 店舗情報
- 店名: Neuer Barber（ノイヤーバーバー）。本店 "frei"（=自由）から生まれた新店。2021年11月6日オープン
- 住所: 大阪市阿倍野区阿倍野筋2-4-48 金村ビル3階南（B）。天王寺駅から徒歩5分
- 電話: 06-6623-1005 / Mail: info@neuer.frei.jp
- 営業時間: 10:00〜20:00
- 定休日: 月曜日と第2・第3火曜
- 予約手段: LINE または 電話。一部スタッフのみHP上に空き状況カレンダー

- HPは日本語のみ

### 2回目打ち合わせでの確認事項（HPとの差分）
- 長田さん個人の営業枠が18:00〜24:00なのに対し、店舗営業は10:00〜20:00。閉店後の利用形態か、別の時間帯かを確認
- 定休日: 店舗は月曜+第2・第3火曜。個人枠では月曜のみで良いか
- 料金とメニュー所要時間（現在は全60分の仮置き）

## 参考予約サイト（RESERVA / glockhairservice）の構造
- 初期画面: 店舗写真 + 「担当者を選択してください」のセレクト1つだけ
- `category-menu.js` を読む限り、担当者選択 → サブカテゴリ → セグメント → メニュー一覧 の順に下へ展開（各段階はAjaxで取得して `.fadeIn()`、未選択の段階は `.hide()`）
- メニュー選択後は別ページ（日時選択）に遷移
- 下部固定タブ: 「予約」「ログイン」
- 担当者選択以降はCloudflareのbot対策で取得不可。構造はスクリプトから推定
