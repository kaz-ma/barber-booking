このマニュアルでは、予約管理アプリ（ホーム画面の「予約管理」アイコン）の使い方を説明します。【画像】の箇所には、公開前に実際の画面のスクリーンショットを入れます。

---

## 0. はじめに覚えておくこと

- 予約管理アプリは **ホーム画面のアイコンから開きます**。Safari のタブで開くと通知が届きません。
- 予約が入ると iPhone に通知が届きます。通知が届かなくても、**アプリを開けば 20 秒以内に「受信箱」に表示されます**。
- お客様の連絡先は **Instagram の DM** です。予約サイトに電話番号は載せていません。
- 迷ったら、何もせずに開発者へ連絡してください（§13）。

| タブ | できること |
|---|---|
| 今日 | 今日の予約とブロック、空き時間。来店・完了の記録 |
| 週 | 1 週間の予約数・空き |
| 受信箱 | 新しい予約・お客様のキャンセル（未確認の件数がバッジに出る） |
| 設定 | 営業時間・メニュー・通知・顧客 |

## 1. 最初の設定（公開前に 1 回だけ）

開発者と一緒に行います。

1. iPhone の Safari で予約サイトの `/admin` を開く（URL は開発者から受け取る）。
2. 画面下の「…」→「共有」→「ホーム画面に追加」→「追加」。
3. ホーム画面に増えた「予約管理」アイコンから開く。
4. 「メールのコードでログインする」→「確認コードを送る」。
5. メールに届いた 6 桁のコードを入力する（キーボードの上に出る候補をタップしても入ります）。
6. 「この端末に Face ID（パスキー）を登録する」→ Face ID。次回からは「Face ID でログイン」だけで入れます。
7. 「設定 > 通知」→「通知をオンにする」→ 確認で「許可」。
8. 「テスト通知を送る」→ 通知が届いたら「届いた」。

【画像】ホーム画面に追加 ／ ログイン ／ 通知をオン

ログインは 30 日間保たれます（使うたびに延長）。

## 2. 毎日の流れ

### 営業前

1. 「予約管理」を開く。
2. タブの「受信箱」に **未確認** の数が出ていたら開き、新しい予約とキャンセルを確認する（行を開くと確認済みになります。「すべて確認済みにする」でまとめて消せます）。
3. 「今日」で今日の予約を時刻順に確認する。

### お客様が来たとき

1. 「今日」で予約をタップ →「予約詳細」。
2. 「来店済みにする」→ 施術を始めたら「施術を開始する」→ 終わったら「完了にする」。
3. 遅刻した場合は「遅刻（分）」に分数を入れておくと記録に残ります。

【画像】予約詳細の状態ボタン

### 前日の夜

- 毎日 21 時台に「明日の予約 n 件」の通知が届きます（21:00〜21:59 のどこか。サーバーの仕様で時刻が少しずれます）。

## 3. DM で予約を受けたとき（手動予約）

**先にアプリに登録してから**お客様に返信します。登録しないと、同じ時間に web の予約が入ってしまいます。

1. 「今日」右下の「追加」→「手動予約を入れる」（日付を変えるときは手動予約の画面で日付を選びます。空いている時間をタップしてもその時刻で始められます）。
2. 「お名前」にふりがなか電話番号を入れると、以前のお客様が候補に出ます。初めての方は「新しいお客様として入力」。
3. メニュー、日付、開始（15 分刻み）を選ぶ。下に「◯◯の空き」が出るので、タップすると開始に入ります。
4. 「経路」で「Instagram の DM」を選ぶ。
5. 「保存する」。ほかの予約と重なっていると保存できません（近い空き時間が表示されます）。
6. 保存後の画面で「**DM 用の文面をコピー**」→ Instagram の DM に貼り付けて送る。英語のお客様は「お客様に送る確認 URL の言語」を English にしてからコピーします。

【画像】手動予約の画面 ／ 保存後の「DM 用の文面をコピー」

- 文面には予約内容とお客様用の確認 URL が入っています。お客様はその URL で予約内容（店名・住所・地図）を見られ、締切までなら自分でキャンセルできます。
- 確認 URL をなくしたお客様には、予約詳細の「確認 URL を発行してコピー」で新しい URL を送れます（**前に送った URL は使えなくなります**）。

---

## 4. 時間をブロックする（休憩・私用）

1. 「今日」右下の「追加」。
2. 「今から 1 時間」「今から 2 時間」「今日はここまで」のどれかをタップ。日時を決めたいときは「期間を指定」（最大 60 日）。
3. 種別（休憩・私用・臨時休業・休業日）とラベル（自分用のメモ）は任意。
4. 画面下に「取り消す」が 5 秒間出ます。間違えたらすぐ押してください。

【画像】ブロックのシート

- ブロックすると、お客様の予約サイトでその時間が予約できなくなります（予約締切より後の枠だけが変わります）。
- **ブロックしても、すでに入っている予約は消えません。** 重なる予約があるときはシートに表示されるので、お客様に DM で連絡してください。
- ブロックを消すときは「今日」でブロックをタップ →「このブロックを削除する」。

---

## 5. 休業日・営業時間・メニューを変える

すべて「設定」から変えられ、保存するとお客様の予約サイトにすぐ反映されます。

### 定休日・営業時間

1. 「設定 > 営業時間」→「毎週の受付時間」。
2. 曜日ごとに「受付」のオン・オフ（オフ＝定休日）と開始・終了を変える。
3. 「変更 n 件を保存する」。

### 臨時休業・時間変更（特定の日だけ）

1. 「設定 > 営業時間」→「臨時休業・時間変更を追加する」。
2. 日付と内容（臨時休業／時間変更）、メモ（任意）→「登録する」。
3. **その日に予約がある場合は「予約が n 件あります」と出ます。予約は自動ではキャンセルされません。** お客様に DM で連絡し、予約詳細で「管理者キャンセルにする」を押してください。

### 予約のルール

「設定 > 営業時間」→「予約枠のルール」で、枠の刻み、締切（何分前まで web 予約できるか）、何日先まで受け付けるか、セルフキャンセル締切、当日予約を受けるかを変えられます。プレビューの文章で結果を確かめてから保存してください。

### メニューの価格・所要時間

1. 「設定 > メニュー」→ 変えたいメニューをタップ。
2. 一般価格、学生価格（空欄＝一般価格と同じ）、所要時間、バッファ（片付けの時間）を変えて保存。
3. 右のスイッチ＝顧客サイトに公開。使わないメニューはスイッチをオフにします（**削除はできません**。非公開でも手動予約では選べます）。
4. 上下の矢印で表示順を変えられます。

【画像】メニュー一覧 ／ メニューの編集

- 価格や所要時間を変えても、**すでに入っている予約はそのまま**です（新しい予約から変わります）。

## 6. 通知が来ないとき

上から順に試してください。

1. アプリを開いて「受信箱」を見る（予約自体は入っているかを確認）。
2. iPhone の「設定」アプリ →「通知」→「予約管理」→「通知を許可」がオンか。
3. 集中モード（おやすみモードなど）で「予約管理」が止められていないか。
4. 予約管理アプリの「設定 > 通知」→「テスト通知を送る」。
5. 届かなければ「届かない」→「**購読を作り直す**」→ もう一度「テスト通知を送る」。
6. 「通知を受け取る端末」に「この端末」がなければ「通知をオンにする」。
7. それでも届かなければ開発者へ連絡（そのあいだは、こまめにアプリを開いて受信箱を確認してください）。

【画像】設定 > 通知

## 7. お客様に見えているもの

| 場面 | お客様の画面 |
|---|---|
| 予約が完了したとき | 予約番号、日時、メニュー、料金、店名・住所（地図）、担当者名が 1 画面に出ます。「カレンダーに追加」と、キャンセル用のリンク（共有・コピー）があります。**確認メールは送られません**（スクリーンショットで保存するよう案内しています） |
| キャンセルしたいとき | 完了画面のリンク（またはカレンダーの予定に入っているリンク）から、**セルフキャンセル締切（初期値: 開始の 2 時間前）まで**自分でキャンセルできます。キャンセルされると通知が届き、その枠はまた予約できるようになります |
| 締切を過ぎたとき | 「Instagram の DM でご連絡ください」と表示されます。DM が来たら §8 の手順で処理します |
| web で予約できる時間 | 開始の 60 分前まで、60 日先まで（初期値。§5 の「予約のルール」で変更） |
| 予約制限があるお客様 | 「ご予約は Instagram の DM で承ります」と表示され、web では予約できません |

予約の確認ページは、予約の終了から 24 時間たつと表示されなくなります。

## 8. 遅刻キャンセル・無断キャンセル・困ったお客様

| 状況 | 予約詳細で押すボタン | 記録 |
|---|---|---|
| 連絡なしで来なかった | 「無断キャンセルにする」（開始から 30 分たつと案内が出ます） | 無断の回数 +1 |
| 締切後に DM でキャンセル、または大幅な遅刻で施術できない | 「遅刻キャンセルにする」 | 遅刻キャンセルの回数 +1 |
| お店の都合、または締切前に DM で依頼された | 「管理者キャンセルにする」 | 回数は増えない |
| 手動予約を間違えて入れた | 「入力ミスとして削除する」 | 統計に含めない |

- 押すとすぐに実行されます。5 秒以内なら画面下の「取り消す」で戻せます。
- キャンセルにすると、その枠はすぐにお客様の予約サイトで空きに戻ります。

**繰り返すお客様への制限**（「設定 > 顧客」→ お客様を検索 → 「予約制限」）:

| 制限 | 内容 |
|---|---|
| 制限なし | 通常どおり |
| Instagram DM のみ受付 | web では予約できず、DM で受けるよう案内される。手動予約は入れられる |
| 受付停止 | web では予約できない |

## 9. お客様から個人情報の依頼があったとき

依頼は Instagram DM で受け、**本人であることを確認してから**行います（予約番号・電話番号の下 4 桁など）。

| 依頼 | 操作 |
|---|---|
| 「自分の情報を見せてほしい」（開示） | 「設定 > 顧客」→ お客様を開く →「JSON でエクスポート」→ できたファイルをお客様に渡す方法は開発者と相談 |
| 「情報を消してほしい」（削除） | 同じ画面の「個人情報の削除（匿名化）」→ 電話番号の下 4 桁を入力 →「匿名化する」→ 確認。**元に戻せません**。氏名・ふりがな・電話番号・備考が消え、予約の日時・メニュー・状態だけが残ります。今後の予約は管理者キャンセルになります |

最後の来店から 3 年たったお客様の個人情報は、毎日の自動処理で同じように匿名化されます。

## 11. やってはいけない操作

| してはいけないこと | 理由 |
|---|---|
| DM で受けた予約をアプリに登録しないまま返信する | 同じ時間に web の予約が入る |
| 本当のキャンセルに「入力ミスとして削除する」を使う | 来店・キャンセルの統計が狂う |
| 臨時休業を登録しただけで、その日のお客様に連絡しない | 予約は自動ではキャンセルされない |
| 確認 URL を Instagram の投稿・ストーリーズに載せる | URL を知っている人は誰でもその予約をキャンセルできる |
| 必要もないのに「確認 URL を発行」を押す | 前に送った URL が使えなくなる |
| 意味が分からないまま「この端末以外をログアウト」を押す | ほかの端末の通知も止まる（端末をなくしたとき用） |
| 本人確認をせずに「匿名化する」を押す | 元に戻せない |
| 予約画面・顧客画面のスクリーンショットを SNS に載せる | お客様の個人情報が写る |
| 集中モードで「予約管理」の通知を止めたままにする | 予約に気づけない |
| Vercel・Neon・GitHub・Cloudflare の画面で、設定・環境変数・データベースを変更・削除する | サイトが止まる、データが消える（開発者が行う） |

開発者向け: `drizzle-kit push`、`VAPID_*`・`PII_HASH_SECRET` の変更、Neon `staging` ブランチの「Reset from parent」（本番の個人情報が複製される）はしない。
